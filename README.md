#  Blush & Bloom Eco Beauty

> A modern eco-beauty website designed to combine clean visual aesthetics, product discovery, and a sustainable beauty experience.

## ✨ Overview

**Blush & Bloom Eco Beauty** is a modern web application created around the concept of sustainable and eco-conscious beauty.

The website focuses on creating a visually engaging shopping experience while presenting beauty products through a clean, elegant and responsive interface.

The project combines modern frontend development with thoughtful UI/UX design to create an aesthetic digital experience for eco-conscious beauty customers.

- 🌸 Modern eco-beauty themed interface
